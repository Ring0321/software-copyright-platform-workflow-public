# Fixed submission template folder

This open-source repository does not include real DOCX/PDF filing templates.

Put your private local templates here before running formal generation:

```text
application-info.txt
manual.docx
manual.pdf
source-code.docx
source-code.pdf
cooperation-agreement.docx
cooperation-agreement.pdf
```

Do not commit real template files if they contain personal identity data, customer names, signatures, historical software names, or platform-only submission content.
